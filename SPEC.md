# ТЗ: VERBORA — Telegram Mini App для изучения английского

> **Название приложения:** VERBORA (от *verb* — глагол; созвучно с «верба»). **Маскот:** Verbi. **Слоган:** «Your language journey with Verbi».
> Автор идеи и дизайна — Валерия (ValValeria).
> Этот файл — техническое задание для сборки. Начинаем с **версии v1** (см. раздел 11), остальное — архитектурно закладываем, но не реализуем сразу.

---

## 1. Суть продукта

Обучающее приложение английского языка внутри Telegram (Mini App + бот).
Концепт похож на Duolingo, но **сильнее в грамматике**: каждая тема строится вокруг понятного правила, ошибки разбираются с объяснением, порядок тем логичный и структурированный.

**Для кого:**
- новички с нуля;
- те, кто учил язык, но подзабыл (нужно «освежить» слабые структуры, а не начинать с am/is/are);
- люди с уверенным уровнем, которые хотят дойти до продвинутого;
- украинцы по всему миру (релокация, работа, быт).

---

## 2. Язык интерфейса и объяснений

- **Украинский — по умолчанию.** Русский — дополнительный.
- Выбор языка — **первый экран онбординга** («Українська / Русский»). Предлагать вариант по `language_code` из Telegram.
- **Переключатель в настройках**, менять можно в любой момент, прогресс не теряется.
- Все тексты интерфейса и учебные объяснения хранятся с ключами `ua` и `ru`. Важно: Telegram в `language_code` отдаёт украинский как `uk` — в коде сопоставлять `uk` → `ua`. Английский контент (слова, примеры, аудио) — общий.
- На будущее: режим «объяснения на английском» для B2+.

---

## 3. Онбординг

1. **Выбор языка** (ua / ru).
2. **Опрос:**
   - Был ли опыт изучения? — *Новичок / Учил(а), но подзабыл(а) / Уверенный уровень*
   - Зачем язык? — *Быт и путешествия / Работа / Учёба и экзамены*
   - Сколько времени в день? — *5 / 15 / 30 минут*
3. **Диагностический тест** (только для не-новичков):
   - 15–20 вопросов, адаптивный (ошибка → вопросы проще, верно → сложнее);
   - результат: стартовый уровень + **карта грамматики**.
4. Новичок → сразу A1, первый урок.

## 4. Структура обучения

### 4.1 Основной путь — уровни CEFR
**A1 → A2 → B1 → B2 → C1** (C2 не делаем).

- Уровень = набор **юнитов**. Юнит = **одна грамматическая тема** + связанная лексика (15–20 слов).
- **Цель пользователя (быт / работа / учёба)** — не отдельный трек, а **акцент**: влияет на приоритет тем и подборку лексики внутри уровня.
- Ориентир по распределению тем по уровням — English Grammar Profile (Cambridge) / CEFR. Весь контент — **авторский**, без копирования учебников.

### 4.2 Карта грамматики
Визуальное дерево тем со статусами:
- 🟢 знаю, 🟡 «плавает», 🔴 пробел / не пройдено, 🔒 закрыто.

### 4.3 Режим «Освежить»
Для тех, кто подзабыл: короткие повторялки по слабым темам — правило за 30 секунд + 5 заданий.

### 4.4 Работа над ошибками
Приложение запоминает, в каких правилах пользователь ошибается, и подаёт их чаще (интервальное повторение).

### 4.5 Дополнительные курсы (отдельный раздел)
- **«Как читать транскрипцию»** — делаем первым (см. раздел 6).
- **IELTS** — позже.
- **Нишевые курсы** (позже): IT-специалисты, бизнес и переговоры, медицина, бьюти и сервис, логистика и водители, отели и рестораны, релокация (врач, банк, аренда, документы, школа).

### 4.6 Серпантин прогресса (главный экран)
Главный экран — извилистый путь уроков (в собственном визуальном стиле, не копия Duolingo).

- **Каждый уровень (A1, A2, B1…) — свой серпантин.**
- **Кружок на пути = урок.** Состояния: пройден ✅, текущий (пульсирует, рядом маскот), закрыт 🔒, «освежить» 🔁 (тема начала «плавать»).
- **Юниты — участки пути** с заголовком (например, «Unit 3 · Present Simple»), у каждого свой цвет.
- **Конец юнита — чекпоинт:** мини-тест по теме + награда (сундучок / бейдж).
- **Конец уровня — финальный тест** → анимация перехода (маскот радуется, «Рівень A1 пройдено 🏆») → пользователя переносит на серпантин следующего уровня.
- **Можно «перепрыгнуть»:** сдать тест чекпоинта и открыть юнит сразу.
- Пройденные уровни остаются доступны: прокрутка вверх или переключатель уровней.
- Диагностика сразу ставит пользователя на нужную точку нужного серпантина, уже известные темы отмечаются пройденными.

**Шапка прогресса над серпантином:**
- Название уровня + **процент прохождения уровня** (например, «A1 · 42%») и прогресс-бар.
- **Маскот показывает процент** — держит/показывает табличку или элемент с числом (точный вид — по дизайну маскота от Валерии). При росте процента — короткая анимация радости.
- Рядом — стрик 🔥 и XP.

Карта грамматики (4.2) остаётся отдельным экраном-обзором; серпантин — ежедневный путь.

## 5. Структура урока

1. **Правило** — один экран: формула, 3 примера, сравнение с родным языком («в українській так, а в англійській так»).
2. **Практика** — типы заданий:
   - выбор варианта (4 опции);
   - вставить пропущенное слово;
   - собрать предложение из слов;
   - найти и исправить ошибку;
   - аудирование: услышал → выбрал / написал.
3. **Разбор ошибок** — не просто «неверно», а объяснение («тут потрібна -s, бо he/she/it»).
4. **Мини-повторение** прошлых тем.
5. *(v2)* **Пересказ / объяснение своими словами** — см. раздел 7.

### Слова (vocabulary)
Каждое слово содержит:
- слово, перевод (ua/ru), **транскрипцию (IPA)**, **кнопку 🔊 озвучки**;
- пример предложения + его озвучка.

Карточки со словами — с интервальным повторением (логика как в Anki).

## 6. Мини-курс «Как читать транскрипцию»

Раздел «Дополнительные курсы → Транскрипция». Уроки:
1. Зачем транскрипция и как её читать (скобки, ударение ˈ, долгота ː).
2. Гласные: короткие и долгие (ship/sheep, full/fool).
3. Дифтонги (/eɪ/, /aɪ/, /əʊ/ …).
4. Сложные согласные (/θ/, /ð/, /ŋ/, /w/, /æ/).
5. Практика: прочитай слово по транскрипции, угадай на слух.
6. Финальный челлендж → скилл **«Читаю транскрипцию» 🏅**.

Формат: короткое видео 30–60 сек + **интерактивная таблица звуков** (тап по символу → звук + примеры слов) + 5–7 заданий.

## 7. Пересказ и живая речь (v2–v3)

- Пользователь читает/слушает короткий текст и пересказывает своими словами; задания вида «объясни, как приготовить кофе», «опиши свой день».
- **v2:** письменный ответ → проверка ИИ через серверную функцию (грамматика + «как сказать естественнее»), ответ на выбранном языке ua/ru.
- **v3:** голосовой ответ (голосовое сообщение боту → распознавание речи → проверка ИИ).

---

## 8. Озвучка (TTS)

- Аудио **генерируется заранее** скриптом: проходит по JSON-контенту, отправляет слова и предложения в TTS-сервис, сохраняет mp3 (`word_apple.mp3`, `u1_l2_ex3.mp3` и т.п.).
- Скрипт **докидывает только недостающие файлы** при добавлении контента.
- Сервис — Google Cloud TTS или Azure (есть бесплатные лимиты); ElevenLabs — опционально.
- Перед этим — **тестовая страница выбора голоса** (одни и те же фразы разными голосами: US/UK, муж/жен). Голос выбирает Валерия, дальше всё приложение звучит одним голосом.
- Фолбэк: браузерный Web Speech API.

## 10. Техническая архитектура

| Часть | Технология |
|---|---|
| Бот | **@verbora_englishbot** — Telegram Bot API (@BotFather): вход в Mini App, напоминания, приём голосовых (v3) |
| Фронтенд | React + Vite (или Vue), Telegram Web App SDK (`telegram-web-app.js`): тема, имя, haptic feedback, MainButton |
| Хостинг | Netlify |

| ИИ | Claude API (или аналог) — проверка пересказов и разбор ошибок |
| Оплата | Telegram Stars (премиум-курсы, снятие лимитов) |
| Админка контента | на старте — таблицы Supabase; позже CMS (например, Directus) |

**Авторизация:** через Telegram `initData`, обязательно проверять подпись на сервере.

**Поток пользователя:**
1. Открывает Mini App из бота → Telegram передаёт `initData`.
2. Приложение подтягивает уровень и прогресс → показывает следующий урок.
3. Ответы сохраняются, ошибки попадают в «работу над ошибками».
4. Вечером бот присылает напоминание («Пора повторити 5 слів 🔥»).

## 12. Формат контента

Контент лежит в `content/<уровень>/unit-XX.json`. **Номер файла = порядок на серпантине**: грамматические и лексические юниты идут одной последовательностью (A1: `unit-01` … `unit-25`, A2: `unit-01` … `unit-23`, B1: `unit-01` … `unit-22`, B2: `unit-01` … `unit-19`, C1: `unit-01` … `unit-16`, см. 13.4–13.8). Финальный тест уровня — `content/<уровень>/final-test.json`. Движок читает эти файлы; добавление урока = добавление JSON без правки кода. **Готово: A1** (25 юнитов, ~1020 заданий в уроках) **A2** (23 юнита, ~915 заданий в уроках), **B1** (22 юнита, ~855 заданий в уроках), **B2** (19 юнитов, ~700 заданий в уроках) и **C1** (16 юнитов, ~510 заданий в уроках) — весь курс A1–C1 — плюс разминки, чекпоинты и финальные тесты. Финальный тест каждого уровня открывает серпантин следующего. Первая разминка уровня берёт задания из последнего юнита предыдущего.

**Структура юнита:** `id`, `level`, `order`, `kind` (`grammar` / `vocab`), `title {en, ua, ru}`, `rule` (общее правило юнита: `formula`, `explain {ua, ru}`, `examples[]`, `compare {ua, ru}`; у лексических юнитов — `null`), `vocab[]`, `lessons[]`, `checkpoint[]` (тест в конце юнита).

**Урок:** `id`, `title {en, ua, ru}`, `recap` (разминка: `from`, `note {ua, ru}`, `exercises[]`; `null` — без разминки, см. 13.2), `rule` (правило подтемы — экран перед заданиями; `null` у урока «Практика» и у лексических уроков), `words[]` (только в лексических уроках: какие слова из `vocab` показать карточками перед заданиями), `exercises[]`.

**Двуязычные поля:** `formula` в правиле и `question` в `choose` бывают строкой (одинаково для всех) или объектом `{ua, ru}` — показывать по языку пользователя.

**Финальный тест:** `id`, `level`, `kind: "final-test"`, `title`, `pass_score` (доля верных ответов, 0.8), `exercises[]` (у каждого задания `source` — id исходного задания).

**Упражнение:** `id` (например `a1-u01-l02-e05`; разминка — `-r01`, чекпоинт — `a1-u01-cp01`), `type`, `topic`, поля типа, `explain {ua, ru}`. Необязательные: `hint` (подсказка, например «I am» для `fill`), `audio` (заполняет TTS-скрипт).

**Слово:** `word`, `ipa`, `ua`, `ru`, `example`, `audio` (путь к mp3, заполняет TTS-скрипт).

**Типы упражнений** — под каждый тип свой компонент:
| type | Что делает | Поля |
|---|---|---|
| `choose` | выбрать вариант | `question`, `options[]`, `answer` |
| `fill` | вписать слово | `question` (с `___`), `answer`, `accept[]` (допустимые варианты) |
| `build` | собрать предложение из слов | `words[]`, `answer` |
| `fix` | найти и исправить ошибку | `sentence`, `answer`, `accept[]` |
| `listen` | услышать и выбрать | `audio_text`, `options[]`, `answer` |
| `translate` | перевести с родного | `prompt {ua, ru}`, `answer`, `accept[]` |
| `ipa` | прочитать транскрипцию | `ipa`, `options[]`, `answer` |
| `match` | соединить пары (начало ↔ конец, слово ↔ определение, слово ↔ перевод) | `pairs[]` (`left`, `right`; `right` — строка или `{ua, ru}`) |
| `wordbank` | вставить слова из банка в несколько предложений | `bank[]`, `reuse` (можно ли брать слово повторно), `sentences[]` (с `___`), `answers[]` |
| `define` | назвать слово по описанию («A person who treats teeth is…») | `definition`, `answer`, `accept[]` |
| `associate` | слово-ассоциация (Car → mechanic) | `cue`, `answer`, `accept[]` |
| `brackets` | текст с пропусками, в скобках — подсказка на родном языке | `text` (с `{{1}}`), `hints[] {ua, ru}`, `answers[]` |
| `reading` | текст или диалог + вопросы к нему | `text` или `dialog[]` (`speaker`, `line`), `audio`, `questions[]` (`choose`: `question`, `options[]`, `answer`; `truefalse`: `statement`, `answer` true/false) |
| `picture` | задание по картинке (например, семейное древо) | `image`, `questions[]` |
| `write` | свободный текст на тему (проверка ИИ, v2) | `prompt {ua, ru}`, `min_words`, `use_vocab[]` |

У каждого упражнения — `explain {ua, ru}` (разбор ошибки) и `topic` (тег правила для «работы над ошибками»).
Проверка закрытых заданий — на клиенте: без учёта регистра, лишних пробелов и точки/знака в конце; апострофы ’ и ' считаются одинаковыми; плюс варианты из `accept[]`. ИИ — только для пересказов.

## 13. Программа обучения (A1–C1)

### 13.1 Нормы объёма
- Юнит = 3–7 уроков + чекпоинт. Каждая подтема — отдельный урок, чтобы не перегружать.
- **Юниты про времена и глаголы — больше уроков (5–7):** отдельно утверждение, отрицание, вопросы, правила написания, сравнение с похожим временем, практика.
- **Урок = 3–5 минут = 8–10 заданий:** экран правила подтемы → 2–3 простых (choose) → 3–4 средних (fill, build, listen) → 2–3 сложных (fix, translate).
- **Последний урок юнита — «Практика»:** все подтемы вперемешку + 1–2 задания на прошлые юниты.
- **Чекпоинт:** 10–12 заданий по юниту; можно сдать сразу, чтобы «перепрыгнуть» юнит.
- **Финальный тест уровня:** 25–30 заданий.

### 13.2 Разминка «Згадаймо / Вспомним» перед каждым уроком
- 30–60 секунд перед началом урока: **1 экран-напоминание** (формула + 1 пример из прошлого урока) и **2–3 быстрых задания** на прошлую тему.
- На первом уроке юнита — напоминание по прошлому юниту и **мостик к новой теме**, если они связаны (например, перед Present Continuous вспоминаем am / is / are; перед Present Perfect — V3 неправильных глаголов).
- Маскот в эмоции «объясняет».
- Если в прошлой теме были ошибки — разминка берёт задания из «работы над ошибками».
- Можно пропустить кнопкой «Пам'ятаю ✓».
- Данные: поле `recap` в уроке (`{ "from": "<id урока/юнита>", "note": {ua, ru}, "exercises": [...] }`). Если `recap` не задан — движок сам берёт правило и 2–3 задания из предыдущего урока.

### 13.3 Тематические юниты лексики 📗
Между грамматическими юнитами (🔤) регулярно идут **юниты лексики** — после каждых 1–3 грамматических. Тема лексики подобрана под только что пройденную грамматику (артикли → профессии: *She is a vet*).

**Структура юнита лексики (5 уроков):**
1. Слова, часть 1 — карточки (слово, IPA, 🔊, пример) + `match`, `choose`
2. Слова, часть 2 — то же + `define`, `associate`
3. Фразы и устойчивые выражения — `brackets`, `translate`
4. В контексте — `reading` (текст или диалог с озвучкой) + `wordbank`
5. Практика — всё вперемешку

**«Розкажи / Расскажи» — бонус, не обязательный:** после каждых 3 юнитов лексики — 3–5 предложений на объединённую тему (например, «о себе и своей семье»). С опорой: начала фраз и слова-подсказки, на A1 — сборка из блоков вместо свободного текста. Не блокирует прогресс по серпантину, даёт бонусные XP / бейдж. Проверка ИИ (v2). Больших сочинений нет.

**Правила адаптации заданий:**
- Открытые задания без однозначного ответа («назови 5 фруктов», «что можно сделать с мясом») превращаются в автопроверяемые: выбор нескольких вариантов, `wordbank`, `match`.
- Задания «переведи текст» → `reading` с вопросами на понимание + `translate` отдельных предложений.
- Задания «поговорите друг с другом» → диалог с озвучкой + `build` реплик.
- Лексика урезается под уровень (A1 — самые частые слова; редкие вроде *partridge* — убрать или перенести выше).
- Реальные бренды и шоу в текстах заменяются вымышленными.

Материалы Валерии (знакомство, профессии, семья, еда, кулинария, покупки продуктов, активный отдых) — **ориентир и вдохновение, а не готовый контент.** Они рассчитаны на учеников среднего уровня, поэтому на A1 уроки пишутся заново и проще (короткие слова и фразы), а её типы заданий, тексты и диалоги в переработанном виде используются ближе к A2–B1 — там же темы можно вернуть «вторым кругом» с более сложной лексикой (I'm fond of…, in-laws, способы готовки).

## 14. Принципы и ограничения

- Весь учебный контент — **авторский**. Чужие курсы и учебники — только как ориентир по темам, без копирования текстов, упражнений и подачи.
- Mobile-first, лёгкий вес, быстрая загрузка внутри Telegram.

## 15. Раздел «Перевір себе / Проверь себя» (диктант с картинками)

Отдельная плитка в главном меню (рядом с «Как читать транскрипцию»). Проверяет, как человек помнит написание слов и узнаёт их на слух. Не входит в серпантин и не блокирует уроки.

### 15.1 Контент
- `content/check-yourself/pool.json` — пул слов (собирается `python3 tools/check_yourself/build.py tools/check_yourself/lucide_names.txt`, источник — `tools/check_yourself/pool.py`).
- 15 тем (еда, дом, транспорт, животные, природа, вещи, тело, учёба, техника, город, хобби, деньги, наука, праздники, профессии), 248 слов, 658 предложений.
- Слово: `id`, `word`, `level` (с какого уровня слово попадает в наборы), `icon` (имя иконки **Lucide**, lucide.dev, лицензия ISC — бесплатно и для коммерции), `ipa`, `ua`, `ru`, `audio`, `sentences[]`.
- Предложение: `id`, `level` (A1…C1), `text`, `audio`. У одного слова предложения разной сложности: на A1 «He drives a car.», на C1 «No sooner had I bought the car than it broke down.»

### 15.2 Набор
- **10 слов**, новый набор **раз в 2 дня** (`pack_size`, `refresh_days` в pool.json). Внутри периода у пользователя всегда один и тот же набор.
- Берутся только слова и предложения **до текущего уровня пользователя включительно**: на A2 — A1+A2, на C1 — всё.
- Набор тематический: тема с ≥ 6 доступными словами, не та же, что в прошлый раз. Если в теме меньше 10 слов — добирается из других тем.
- Предложение для слова — самое сложное из доступных по уровню; с B1 иногда (30 %) на ступень проще, для разнообразия.
- До 3 слов, где пользователь ошибся в прошлых наборах, возвращаются в следующий набор.
- Эталонная логика: `tools/check_yourself/pack.js` → `buildPack(pool, { userId, level, now, history })`, плюс `normalize()` и `compareWords()` для проверки ответа. В профиле пользователя храним `history`: `lastThemeId`, `recentWordIds` (последние ~30), `missedWordIds`.

### 15.3 Экран задания (2 шага на слово)
Вверху — полоска прогресса набора (1/10 … 10/10).

**Шаг 1 — «Напиши слово» (без звука).**
- По центру — линейная иконка слова (Lucide, цвет из токенов дизайна, ~96 px, stroke 1.5).
- Ниже — ячейки по числу букв (пробел в составных словах — промежуток: `ice cream`).
- Пользователь печатает; когда все ячейки заполнены — проверка: верные буквы зелёные, неверные красные, можно исправить.
- Подсказки (каждая снимает отметку «без подсказок» для этого слова): 💡 перевод ua/ru (по языку интерфейса), 🔤 открыть следующую букву.
- После 2 неверных попыток показываем правильное написание и IPA → «Далі».
- После верного ответа слово звучит один раз (`word.audio`), под ним появляется IPA.

**Шаг 2 — «Напиши на слух».**
- Под словом появляется предложение в виде ячеек: для каждого слова — подчёркивание по длине, знаки препинания уже стоят.
- Предложение **сразу озвучивается**; кнопки 🔊 повторить, 🐢 медленнее (playbackRate 0.7), 💡 открыть следующее слово.
- Проверка — через `compareWords()`: регистр, апострофы ’/' и пунктуация не учитываются. Верные слова зелёные, ошибочные красные с правильным вариантом.
- После 2 неверных попыток показываем правильное предложение → «Далі».
- Текстового перевода предложения нет (это аудирование).

### 15.4 Итог набора
- «Готово! Без підказок 8/10» + сетка иконок всех слов набора (ошибочные помечены) + Verbi с эмоцией по результату (10/10 — восторг, < 5 — поддержка).
- Кнопки: «Ще раз» (тот же набор), «Повторити помилки» (только ошибочные), «На головну».
- XP за набор, отметка в стрике. Скилл 🏅 «Пишу на слух» — после 10 наборов с результатом ≥ 8/10.
- На плитке в меню: «Новий набір!» или таймер «Новий набір через 1 д 5 год».

### 15.5 Озвучка
TTS-скрипт озвучивает `word` и каждое `sentence.text` тем же голосом, что и уроки; имена файлов — по id (`cy_food-01.mp3`, `cy_food-01-s2.mp3`), путь пишется в поле `audio`.
